# 深蓝立方宣传页

这个文件夹是一个纯静态网站，可直接作为 3D 打印农场的中文宣传页使用。

## 文件

- `index.html` - 页面结构与中文内容
- `styles.css` - 响应式样式
- `script.js` - 移动端菜单与玩具分类切换
- `assets/products/` - 产品图片

## 产品方向

- 3D打印耗材
- 玩具
  - 小人
  - 解压玩具
  - 桌面摆件
  - 收纳
- 定制产品
- 打印机配件

## 静态部署

把整个 `matterforge-site` 文件夹作为站点根目录上传即可。

常见设置：

- Build command：留空
- Output directory：`.` 或 `/`
- Entry file：`index.html`
- Node version：不需要

上传时请保持 `assets` 文件夹与 `index.html` 在同一级目录。
